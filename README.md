# Snake Game 

A classic 2D Snake game developed in **Java** using the **Processing** framework as part of a 2nd-year Bachelor's degree (L2) project.

##  Gameplay & Features
* **Classic Mechanics:** Control the snake, eat food to grow, and avoid hitting the walls or your own tail.
* **Score System:** Tracks your current score as the snake grows.
* **Graphics:** Rendered using the Processing library.

## Technologies
* **Language:** Java
* **Library:** Processing
